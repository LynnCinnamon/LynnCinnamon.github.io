Datenschutzerklärung – Local AI (privat)

Stand: November 2026

Wer nutzt die App?

Ausschließlich der Betreiber selbst, mit dem eigenen Google-Konto. Die App wird niemand anderem angeboten.

Welche Google-Daten werden genutzt?

  • Gmail lesen (gmail.readonly): Mails suchen und Inhalte abrufen, wenn ich das im Gespräch anfordere oder freigebe.
  • Gmail-Entwürfe (gmail.compose): Entwürfe anlegen. Die App sendet keine Mails.

Wo werden die Daten verarbeitet?

  • Nur auf meinem eigenen Rechner. Das Sprachmodell läuft lokal; Mailinhalte werden an keinen KI-Anbieter oder sonstigen Dritten übertragen.
  • Zugangsdaten (OAuth-Tokens) liegen in einer lokalen Datei auf diesem Rechner.
  • Gesprächsverläufe, in denen Mailinhalte vorkommen können, werden lokal gespeichert und können jederzeit gelöscht werden.
  • Es gibt keinen Server, keine Analyse, kein Tracking, keine Werbung und keinen Verkauf von Daten.

Widerruf

Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen.

English summary

Local AI is a private, single-user tool used only by its owner with their own Google account. It uses gmail.readonly to search and read the owner's emails and gmail.compose to create drafts; it never sends email. All processing happens on the owner's own computer with a locally running language model. Google user data is not transferred to any third party, not used for advertising, not sold, and not used to train models. OAuth tokens and chat history are stored locally and can be deleted at any time. Access can be revoked at myaccount.google.com/permissions.

Local AI's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
